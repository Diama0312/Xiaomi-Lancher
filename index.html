Αυτόματος συγχρονισμός των δικών σου εφαρμογών, των καναλιών TV, των θυρών HDMI και σύνδεση με το AI.

Αυτόματη Λειτουργία στην Τηλεόραση: Όταν συνδεθεί με την Xiaomi TV Max 85", αυτό το παράθυρο οδηγού **εξαφανίζεται αυτόματα**, φορτώνονται οι **δικές σου εφαρμογές**, και όταν πατάς **Netflix** ή **TV**, ανοίγει κανονικά η αυθεντική εφαρμογή του Netflix και η κανονική τηλεόραση (Digea)!
Κώδικας Σύνδεσης (`xiaomi_tv_bridge.py`) + Επαναφορά Εργοστασιακού Μενού: 
# 1. Στην Xiaomi TV Max 85": Ρυθμίσεις -> Σύστημα -> Πληροφορίες -> Πάτα 7 φορές στο "Build" -> Ενεργοποίησε το "Wireless Debugging"
# 2. Στο PC σου: pip install flask flask-cors
# 3. Τρέξε: python xiaomi_tv_bridge.py
# (ΑΝ ΘΕΛΕΙΣ ΝΑ ΓΥΡΙΣΕΙΣ ΣΤΟ ΕΡΓΟΣΤΑΣΙΑΚΟ ΜΕΝΟΥ ΤΗΣ XIAOMI: adb shell pm enable --user 0 com.google.android.apps.tv.launcherx)

import subprocess
from flask import Flask, request, jsonify
from flask_cors import CORS

TV_IP = "192.168.1.50:5555"  # Βάλε την IP της Xiaomi TV Max 85"
app = Flask(__name__)
CORS(app)

def adb(cmd):
    return subprocess.getoutput(f"adb -s {TV_IP} {cmd}")

@app.route("/status", methods=["GET"])
def status():
    out = adb("shell getprop ro.product.model")
    return jsonify({"connected": True, "model": out.strip() or "Xiaomi TV Max 85 (2025)"})

@app.route("/apps", methods=["GET"])
def get_installed_apps():
    raw = adb("shell pm list packages -3")
    pkgs = [line.replace("package:", "").strip() for line in raw.splitlines() if line.startswith("package:")]
    return jsonify({"packages": pkgs})

@app.route("/launch_app", methods=["POST"])
def launch_app():
    pkg = request.json.get("package")
    adb(f"shell monkey -p {pkg} -c android.intent.category.LEANBACK_LAUNCHER 1")
    return jsonify({"ok": True, "launched": pkg})

@app.route("/live_tv", methods=["POST"])
def open_live_tv():
    # Ανοίγει κατευθείαν την κανονική τηλεόραση (Κεραία / Digea) της Xiaomi TV!
    adb("shell input keyevent 170") # KEYCODE_TV
    return jsonify({"ok": True})

@app.route("/netflix_watch", methods=["POST"])
def netflix_watch():
    watch_id = request.json.get("watchId", "81098494")
    adb(f'shell am start -n com.netflix.ninja/.MainActivity -a android.intent.action.VIEW -d "http://www.netflix.com/watch/{watch_id}"')
    return jsonify({"ok": True, "watchId": watch_id})

if __name__ == "__main__":
    subprocess.getoutput(f"adb connect {TV_IP}")
    app.run(host="0.0.0.0", port=8765)
